## 🧾 Campaign at a glance

| Item | Plan |
|---|---|
| **Business** | FitNest Studio (fictional) — gym & group classes, Kondapur, Hyderabad |
| **Business outcome** | More trial visits → more memberships |
| **Offer** | Free 3-day trial pass |
| **Meta objective** | **Leads** (Instant Form) |
| **Audience** | 3 cold ad sets (Broad Local · Fitness Interests · Working Professionals) + 1 Retargeting |
| **Placements** | FB/IG Feed, Stories, Reels (manual in test, Advantage+ later) |
| **Creatives** | 2 × 1080×1080 feed images, 1 × 1080×1920 Story/Reel |
| **Budget** | ₹15,000 for 28 days — ₹4,200 test (Week 1), ₹10,500 scale, ₹300 buffer |
| **Primary KPI** | Cost per Lead ≤ ₹150 |
| **Forecast** | ~103 leads · ~₹143 CPL · ~13 new members · ~2.2x first-month ROAS |

```
Campaign: FitNest_Leads_FreeTrial_Nov26  (Objective: Leads)
├── AS1  Broad Local 5 km           ₹200/day  Day 1–7   → Ads A, B, C
├── AS2  Fitness Interests 8 km     ₹200/day  Day 1–7   → Ads A, B, C
```

## 🛠️ Tools used
- **Meta Ads Manager** — campaign, ad set & ad structure, audience sizing, placements, Instant Form
- **Canva** — ad creative design (1:1 feed, 9:16 Stories/Reels)
- **Google Sheets** — budget plan, performance forecast, weekly KPI tracker

## 💡 Key learnings
1. **Match the objective to the business outcome.** A gym trial needs contact details → *Leads*, not *Traffic* or *Awareness*.
2. **Test small, then scale.** One week at ₹600/day across 3 audiences finds the cheapest CPL before the big spend.
3. **Change one thing at a time.** Same ads in every ad set means the test measures the *audience*.
4. **One primary KPI, several diagnostic KPIs.** CPL decides; CTR, CPM, form CVR and frequency explain.
5. **Creative is targeting now.** Different hooks (offer, social proof, desk-worker pain) attract different people.
